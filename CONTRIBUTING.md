# Contributing to CodeX-RAY

Thanks for contributing. Please open an issue before starting large changes so the scope can be discussed.

## Development setup

1. Install Python 3.10+ and Node.js 18+.
2. Install backend dependencies with `pip install -r requirements.txt`.
3. Install frontend dependencies with `npm install --prefix frontend`.
4. Run `npm run check` before opening a pull request.

## Pull requests

Keep each pull request focused, include tests for behavior changes, and update the README or changelog when a user-facing behavior changes. Do not commit generated caches, local scan history, or credentials. By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

## Code style

Follow the existing Python and JavaScript style. Prefer clear names, small functions, and comments that explain non-obvious decisions.
